# manipuNet

**manipuNet** is a terminal tool for scanning your network. Discover connected devices, inspect them in detail, scan ports, and optionally take action against unwanted devices (requires a Wi-Fi card with monitor mode).

## About

The main goal of this tool is to give you a way to manage your network on a higher level and take action on it.

- Discover all devices connected to your network with basic details about each.
- Scan other network segments if present.
- Take actions against unwanted devices (may require a Wi-Fi card with monitor mode).
- Scan ports on specific devices.

## Warning
This is the early stage of this project so most of the promised abilities are currently under development. Thank you for your patience.
